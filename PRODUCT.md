# ArchMind

ArchMind is an AI architecture workbench. Users describe a system or import a repository, then inspect, revise, compare, simulate, and export its architecture. The backend validates mutation commands; the frontend renders the resulting graph deterministically.

The existing project supports guest projects, chat-based requirements and editing, manual graph editing, node rationale and source citations, version history, comparisons, cost/capacity analysis, load and failure simulation, and starter-kit exports. Preserve those functions and factual claims.

Working audience assumption, inferred from the repository: developers and architecture learners designing a system or understanding an existing codebase. No user-research claims are made.

The user authorized a complete visual upgrade across landing and editor, including colors, typography, layout, animation, and effects. The accepted direction is a modern architecture studio: graphite surfaces, electric-blue actions, clear technical typography, meaningful graph motion, and a warm-white light theme. Keep health colors semantic and preserve reduced-motion access. This direction is settled; implementation should not reopen the visual selection.

Success: an immediately understandable product demonstration and a readable, calm workbench where users can create, inspect, revise and validate a design. Backend semantics, validation rules and project data remain authoritative.
